# Nuvora — The Intelligent Operating System for Modern Business

Nuvora is a modern, high-performance SaaS landing page crafted with an aesthetic light-mode palette, crisp typography (Outfit & Inter), and interactive micro-interactions.

## ✨ Highlights & Features
- **Aesthetic UI/UX:** Clean white layout paired with vibrant sky-blue accents and soft drop shadows.
- **Modern Typography:** Styled with Google Fonts (`Outfit` for headings, `Inter` for body text).
- **Interactive Components:**
  - Dynamic pricing switcher (Monthly / Annual billing toggle with 20% discount badge).
  - Responsive navigation with mobile slide-out menu.
  - Interactive FAQ accordion system.
  - Live metric counters & floating dashboard preview animations.
- **Custom Aesthetic Favicon:** Embedded scalable SVG favicon with geometric 'N' emblem.
- **Comprehensive Sections:** Hero with interactive preview, Value Proposition, Feature Deep-Dives, Product Showcase, Use Cases, Interactive Integrations Hub, Metrics, Testimonials, Feature Comparison Matrix, Blog/Insights, and FAQ.

## 🚀 Quick Start
Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python3 -m http.server 8000

# or using Node / npx
npx serve
```

Then visit `http://localhost:8000` in your browser.

## 🛠️ Tech Stack
- **HTML5:** Semantic, accessible layout.
- **CSS3:** Custom properties (CSS variables), CSS Grid, Flexbox, Keyframe animations, Glassmorphism.
- **JavaScript (Vanilla ES6+):** Scroll reveals, mobile drawer, accordion toggle, dynamic pricing calculator.
